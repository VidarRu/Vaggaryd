# vaggaryd
En liten sida för bibliotekarierna i Värnamo och Vaggeryd

Workshopmaterialet från AI-utbildningen 14 april 2026, i samma grafiska stil som
*AI i folkbibliotekets praktik*: startsida med lösenord, en del per workshop med
bockar och framstegsmätare, presentationen att ladda ner och resurser att ta med hem.

- `index.html` – sidan
- `assets/css/style.css`, `assets/js/main.js` – stil och interaktion
- `assets/img/` – bakgrundsbild och omslag (tagna ur presentationen)
- `material/` – presentationen som PDF

Lösenordet är bara en enkel spärr för besökare. Sidan och materialet ligger öppet här på GitHub.
